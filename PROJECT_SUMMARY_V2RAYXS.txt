V2RayXS / VLESS project summary
Updated: 2026-08-31

Purpose
- Make V2RayXS 1.5.9 on an Intel Mac work reliably with VLESS/REALITY servers from a dynamic GitHub source.
- Avoid broken raw.githubusercontent.com access on this Mac/network by using GitHub Pages.
- Automatically validate servers, publish working ones, install/update them in V2RayXS, and keep 10 automatic profiles.

Mac / app
- V2RayXS: 1.5.9 x86_64
- Bundled Xray: 1.8.4, darwin/amd64
- V2RayXS app path: /Applications/V2RayXS.app
- Xray path: /Applications/V2RayXS.app/Contents/Resources/xray
- Local proxies: SOCKS5 127.0.0.1:1081, HTTP 127.0.0.1:8001
- Global Mode and loaded core were verified to work.
- Chrome initially bypassed V2RayXS because extension “1VPN / Free VPN” controlled Chrome proxy settings. Disabling/removing that extension fixed Chrome; Safari and Chrome both then showed VPN IP 104.28.223.45 / Vilnius / Cloudflare.
- Telegram may need its own proxy setting: SOCKS5 127.0.0.1 port 1081.

Main repository
- https://github.com/StarLordKarma/vless-subscription
- GitHub Pages base: https://starlordkarma.github.io/vless-subscription/

Upstream source
- https://raw.githubusercontent.com/luxxuria/harvester/refs/heads/main/speed_tested.txt
- Direct raw.githubusercontent.com access from this Mac timed out, while github.com / GitHub Pages worked. Therefore Pages is used for Mac delivery.

Important repository files
- .github/workflows/update.yml
  * Runs hourly (cron 17 * * * *) and manually.
  * Downloads upstream speed_tested.txt.
  * Normalizes VLESS links for V2RayXS 1.5.9.
  * Installs Xray 1.8.4 in GitHub Actions.
  * Validates all VLESS servers end-to-end using scripts/validate_vless.py.
  * Creates working and unique working server lists.
  * Builds top-10 V2RayXS outbounds.
  * Commits updated results back to the repo.

- scripts/validate_vless.py
  * Performs actual Xray-based end-to-end checks, not only TCP-port checks.

- scripts/build_v2rayxs_outbounds.py
  * Builds v2rayxs_top10.json and per-profile JSON files in outbounds-auto/.
  * Current requirement: prioritize working servers from these countries first:
    1) USA
    2) United Kingdom
    3) Switzerland
    4) Netherlands
    5) Norway
  * If fewer than 10 preferred-country servers are available, fill remaining slots from other working countries.
  * Server menu tags should show country instead of speed where useful, e.g. AUTO-01-USA, AUTO-02-UK, AUTO-03-Switzerland.
  * Country is determined automatically from the server endpoint/IP during generation.

- v2rayxs_top10.json
  * The 10 automatic outbound profiles consumed by the Mac updater.

- outbounds-auto/
  * Individual JSON files for the generated AUTO-* profiles.

- mac/v2rayxs_auto_update.py
  * Downloads https://starlordkarma.github.io/vless-subscription/v2rayxs_top10.json
  * Reads V2RayXS preferences from domain cenmrev.V2RayXS.
  * Catalina/Python 2.7 plist issue was fixed by converting exported prefs to XML with plutil before plistlib parsing.
  * Preserves manual profiles and replaces only profiles whose tag starts with AUTO-.
  * Sets appStatus proxyState=True and proxyMode=1 (Global Mode).
  * Sets selectedServerIndex to the first AUTO-* profile so AUTO-01 becomes the active server.
  * Disables Use All/custom profile for automatic selection.
  * Restarts V2RayXS only when needed.

- mac/install_v2rayxs_auto.sh
  * One-time installer for the Mac.
  * Installs LaunchAgent and updater.
  * Runs at login and every hour.
  * The updater is self-updating from GitHub Pages, so later fixes can be picked up automatically.

One-time installer command used on the Mac
curl -fsSL https://starlordkarma.github.io/vless-subscription/mac/install_v2rayxs_auto.sh | bash

Observed successful installation output
- Updated 10 automatic V2RayXS servers
- V2RayXS automatic updates installed.
- 10 validated servers refresh at login and every hour.

V2RayXS internals confirmed from v1.5.9 source
- Preferences domain: cenmrev.V2RayXS
- Profiles are stored in NSUserDefaults key profiles.
- Runtime state is in appStatus.
- Selected server key: appStatus.selectedServerIndex
- proxyState controls whether proxy/core service is enabled.
- proxyMode=1 corresponds to Global Mode.
- Menu server selection uses the same selectedServerIndex.

Manual verification history
- Manual outbound 494Mb (lt.superbuba.top:443) successfully established VLESS/REALITY/XTLS traffic.
- access.log showed [httpinbound -> 494Mb].
- error.log showed dialing/tunneling and XTLS processing, proving the VLESS/REALITY path worked.
- Safari then showed changed external IP, proving the tunnel worked.
- Chrome only started using the same tunnel after the old 1VPN extension was disabled.

Current desired steady state
- GitHub checks the full upstream server list hourly.
- The top 10 working unique servers are generated automatically.
- Preferred geography: USA, UK, Switzerland, Netherlands, Norway first.
- Tags in V2RayXS clearly show country.
- Mac updater refreshes AUTO-* profiles every hour and at login.
- Manual servers remain untouched as fallback.
- AUTO-01 should be selected automatically as the active profile.
- Global Mode and core should be enabled automatically.
